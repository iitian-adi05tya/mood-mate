# Mood Mate

**Mood Mate** is a web application designed to assist users in managing depression by tracking their moods and emotions over time. It provides an intuitive interface for users to log their moods and visualize emotional patterns.

## Table of Contents

- [Features](#features)
- [Tech Stack](#tech-stack)


## Features

- **User Authentication**: Secure login and signup using JWT.
- **Mood Tracking**: Log mood entries and track progress visually over time.
- **Interactive UI**: Built with React and Next.js for a seamless user experience.
- **Secure Data Storage**: User data is securely stored using MongoDB.
- **Backend APIs**: Integrated with a backend to handle mood logs and user authentication.

## Tech Stack

- **Frontend**: React.js, Next.js
- **Backend**: Node.js, Express
- **Database**: MongoDB (for storing user data)
- **Authentication**: JSON Web Token (JWT)
